# assets/photos/

Déposez ici **les vraies photos de Totem** — et uniquement celles-là.

Règle du projet : aucune image générée, aucune photo de banque d'images,
aucun visuel « d'ambiance » qui ne serait pas le commerce lui-même.

Sources acceptables :
- les photos de la fiche Google Maps du commerce
  (<https://maps.app.goo.gl/biE6Pykx8JtbwdE49>, onglet « Photos et vidéos ») ;
- des photos prises sur place ;
- des photos fournies par le gérant.

Suggestions de prises de vue utiles (dans l'ordre d'impact) :

| Fichier suggéré | Sujet |
|---|---|
| `devanture.jpg` | La façade avec l'enseigne et la carotte, depuis le trottoir |
| `interieur.jpg` | Le comptoir et les rayons presse |
| `presse.jpg` | Le linéaire journaux / magazines |
| `colis.jpg` | Le coin point relais |

Une fois les fichiers déposés, déclarez-les dans `../../js/photos.js` : la
section « Totem en images » du site s'affiche alors automatiquement.
